# Bitbucket-Contributions-Heatmap
Como minha atuação acontece muito mais por lá do que no GitHub, meu gráfico de contribuições por aqui acaba ficando meio vazio.  Então resolvi criar minha própria solução para ter esse acompanhamento também no Bitbucket e visualizar o histórico de contribuições dos projetos com os quais trabalho no dia a dia.
